**Supercharge your Minecraft\!** 🚀 Velocita Optimized is a modpack designed to make your game run faster and smoother, without changing the core Minecraft experience. We also offer optional tweaks to make things even better\!

## What is Velocita Optimized?

Velocita Optimized is all about giving you the best Minecraft performance possible. That means:

- **💨 Faster Game:** Enjoy higher FPS and reduced lag.
- **🔧 Smooth Gameplay:** Experience fewer stutters and smoother loading.
- **💪 Efficient:** The modpack uses your computer's resources wisely.
- **🎮 Works Everywhere:** Great for both older and newer computers.
- **✨ Optional Enhancements:** Choose "Plus" versions for extra quality-of-life features.

## Features

- 🚀 **Significant performance improvements:** Get more FPS and less lag.
- 🛠️ **Quality of life improvements (Plus versions):** Adds helpful tweaks to the game (in "Plus" versions).
- 📊 **Better resource management:** Uses your computer's power efficiently.
- 🖥️ **Optimized for all systems:** Runs well on both low-end and high-end PCs.
- ✅ **Maintains Vanilla Feel:** Keeps the core Minecraft experience intact.

## Installation

Here's how to get Velocita Optimized up and running:

### Using GitHub (Manual Install)

1. **Go to the Modrinth Folder:** In this GitHub repository, find the "Modrinth" folder.
2. **Choose a Version:**
      - **"Plus" Versions:** These include extra quality-of-life mods.
      - **"Pure" Versions:** These focus only on performance.
3. **Select a Minecraft Version:** Pick the version of Minecraft you want to play.
4. **Download the Modpack:** Download the modpack files.
5. **Import to Your Launcher:** Open your Minecraft launcher (like Prism, PolyMC, or the official launcher).
6. **Import the Modpack:** Import the downloaded files into your launcher.  (Each launcher has a slightly different way to do this; check your launcher's instructions if you're not sure.)
7. **Install and Play:** Let the launcher download the mods, and then you're ready to play\!

### Using Modrinth App (Recommended)

The easiest way to install Velocita Optimized is with the Modrinth App:

1. **Visit the Modrinth Page:** Go to the Velocita Optimized page on Modrinth: [Modrinth Page](https://modrinth.com/modpack/velocita-optimized)
2. **Choose a Version:** Select the Minecraft version and Velocita Optimized version you want.
3. **Install:**
      - **"Install with Modrinth App":** If you have the Modrinth App installed, click this button for automatic installation.
      - **Download Manually:** If you prefer, you can download the files manually and import them into your launcher (see "Using GitHub" above).
4. **Follow the Prompts:** Follow the on-screen instructions to finish the installation.

## System Requirements

To run Velocita Optimized, your computer should have at least:

- **Minimum RAM:** 2GB allocated to Minecraft
- **Recommended RAM:** 4GB allocated to Minecraft
- **Java:** Java 17 or higher
